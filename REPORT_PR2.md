## 3. Индивидуальный проект

Название проекта: Система планирования праздничного меню.

На ПР2 были реализованы следующие функции:

- расчет количества порций по числу гостей;
- расчет общего количества ингредиентов для блюда;
- поиск блюда по названию;
- добавление блюда в меню события;
- удаление блюда из меню события;
- проверка наличия блюда в меню события;
- сортировка блюд по названию;
- подсчет статистики по типам блюд;
- загрузка и сохранение данных в JSON-файлах.

Структура модулей проекта:

- `main.py` - запуск сценария и вывод результата работы программы;
- `menu_planning/calculations.py` - функции расчета порций и ингредиентов;
- `menu_planning/dishes.py` - функции поиска, сортировки и статистики блюд;
- `menu_planning/events.py` - функции работы с меню события;
- `menu_planning/storage.py` - функции загрузки и сохранения JSON-файлов;
- `tests/` - автоматизированные тесты pytest.

Формат хранения данных: данные хранятся в JSON-файлах. В файле `data/events.json` хранится список событий, дата, количество гостей и меню события. В файле `data/dishes.json` хранится список блюд, тип блюда и ингредиенты с количеством на одного гостя.
