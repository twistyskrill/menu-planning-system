# Система планирования праздничного меню

Консольное приложение для планирования праздничного меню, учета блюд и расчета количества ингредиентов для события.

## Возможности

- просмотр событий;
- просмотр и поиск блюд;
- проверка наличия блюда в меню события;
- добавление блюда в меню события;
- удаление блюда из меню события;
- просмотр меню события;
- расчет количества ингредиентов по числу гостей;
- сортировка блюд и вывод статистики;
- сохранение и загрузка данных из JSON-файлов.

## Структура проекта

- `main.py` - точка запуска программы;
- `menu_planning/calculations.py` - расчеты порций и ингредиентов;
- `menu_planning/dishes.py` - работа с блюдами;
- `menu_planning/events.py` - работа с событиями и меню;
- `menu_planning/storage.py` - сохранение и загрузка данных;
- `menu_planning/utils.py` - вспомогательные функции;
- `data/` - JSON-файлы данных;
- `tests/` - автоматизированные тесты;
- `requirements.txt` - зависимости для проверки проекта.

## Формат данных

- `data/events.json` - события, дата, количество гостей и меню;
- `data/dishes.json` - блюда, типы блюд и ингредиенты.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

После запуска программа показывает меню:

```text
=== Система планирования праздничного меню ===
1. Показать события
2. Показать блюда
3. Найти блюдо по названию
4. Проверить блюдо в меню события
5. Добавить блюдо в меню события
6. Удалить блюдо из меню события
7. Показать меню события
8. Выход
```
