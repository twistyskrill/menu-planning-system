# Система планирования праздничного меню

## Назначение

Приложение предназначено для планирования праздничного меню. Оно помогает определить блюдо для события, нужный ингредиент и количество ингредиента с учетом числа гостей.

На первом этапе реализован простой сценарий: расчет количества одного ингредиента для одного блюда.

## Целевая аудитория

Пользователями приложения могут быть:

- люди, которые самостоятельно готовят меню для домашнего праздника;
- семьи, планирующие день рождения, Новый год, юбилей или другое событие;
- начинающие организаторы небольших мероприятий;
- пользователи, которым нужно заранее рассчитать продукты для блюда.

## Предметная область

Предметная область проекта - планирование праздничного меню. При подготовке события пользователь определяет название события, количество гостей, блюда и ингредиенты. Для каждого блюда нужно понимать, сколько порций потребуется и какое количество ингредиентов необходимо подготовить.

В дальнейшем система сможет хранить несколько событий, набор блюд для каждого события, состав блюд и количество ингредиентов. Это позволит автоматически формировать меню и список покупок.

## Основные сущности

- Событие - праздник или встреча, для которой составляется меню.
- Блюдо - позиция праздничного меню.
- Ингредиент - продукт, входящий в состав блюда.
- Количество - объем или масса ингредиента, необходимая для приготовления блюда.
- Гость - участник события, влияющий на количество порций.
- Порция - расчетная часть блюда на одного гостя.

## Основные функции

- расчет количества порций по числу гостей;
- расчет общего количества ингредиента;
- определение типа блюда.

## План развития

На следующих этапах планируется:
