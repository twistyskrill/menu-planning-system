# Система планирования праздничного меню

## Назначение

Система планирования праздничного меню - консольное приложение для учета событий, блюд и ингредиентов.

Приложение позволяет:

- просматривать события;
- просматривать и искать блюда;
- проверять наличие блюда в меню события;
- добавлять блюда в меню события;
- удалять блюда из меню события;
- просматривать меню события;
- рассчитывать количество ингредиентов по числу гостей;
- сортировать блюда;
- выводить статистику по типам блюд;
- хранить данные между запусками приложения.

## Целевая аудитория

Пользователями приложения являются люди, которым нужно подготовить праздничное меню для события: дня рождения, семейного ужина, Нового года или другого мероприятия.

Приложение помогает заранее определить блюда, состав меню и количество ингредиентов с учетом числа гостей.

## Предметная область

Основными объектами предметной области являются:

- событие;
- блюдо;
- ингредиент.

Событие содержит дату, количество гостей и меню. Меню события состоит из объектов блюд. Каждое блюдо содержит тип блюда и список ингредиентов. Ингредиент хранит название продукта и количество в граммах на одного гостя.

При выводе меню программа рассчитывает, сколько каждого ингредиента нужно подготовить для выбранного события.

## Основные сущности

### `Ingredient` - ингредиент

Объект `Ingredient` представляет продукт, входящий в состав блюда.

Основные атрибуты:

- `name` - название ингредиента;
- `grams_for_guest` - количество ингредиента в граммах на одного гостя.

Основные методы:

- `amount_for_guests()` - расчет количества ингредиента для заданного числа гостей;
- `__str__()` - строковое представление ингредиента.

### `Dish` - блюдо

Объект `Dish` представляет блюдо праздничного меню.

Основные атрибуты:

- `name` - название блюда;
- `dish_type` - тип блюда;
- `ingredients` - список объектов `Ingredient`.

Основные методы:

- `get_total_ingredients()` - расчет всех ингредиентов блюда для события;
- `to_data()` - преобразование объекта в словарь для сохранения в JSON;
- `__str__()` - строковое представление блюда.

### `Event` - событие

Объект `Event` представляет событие, для которого составляется меню.

Основные атрибуты:

- `name` - название события;
- `event_date` - дата события;
- `guests` - количество гостей;
- `menu` - список объектов `Dish`.

Основные методы:

- `has_dish()` - проверка наличия блюда в меню;
- `add_dish()` - добавление блюда в меню;
- `remove_dish()` - удаление блюда из меню;
- `to_data()` - преобразование объекта в словарь для сохранения в JSON;
- `__str__()` - строковое представление события.

## Основные операции

### Работа с событиями

- просмотр списка событий;
- поиск события по названию;
- просмотр меню события;
- добавление блюда в меню события;
- удаление блюда из меню события;
- проверка наличия блюда в меню события.

### Работа с блюдами

- просмотр списка блюд;
- поиск блюда по названию;
- сортировка блюд по названию;
- подсчет статистики по типам блюд.

### Работа с ингредиентами

- хранение количества ингредиента на одного гостя;
- расчет количества ингредиента для всех гостей события;
- вывод ингредиентов блюда.

## Взаимодействие объектов

При запуске приложения данные из JSON-файлов преобразуются в объекты `Event`, `Dish` и `Ingredient`.

Объект `Event` хранит список объектов `Dish`. Каждый объект `Dish` хранит список объектов `Ingredient`. При просмотре меню события программа обращается к объектам блюд и рассчитывает количество ингредиентов для числа гостей события.

При сохранении данные преобразуются обратно в словари и записываются в JSON-файлы.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

- `data/events.json`;
- `data/dishes.json`.

В файле `events.json` меню хранится как список названий блюд. При загрузке эти названия связываются с объектами `Dish`, поэтому внутри программы событие работает не со строками, а с объектами блюд.

В файле `dishes.json` хранятся названия блюд, типы блюд и ингредиенты.

## Назначение модулей

### `main.py`

Точка входа в приложение.

Отвечает за:

- запуск приложения;
- отображение консольного меню;
- получение данных от пользователя;
- вызов функций проекта.

### `menu_planning/models.py`

Содержит классы предметной области:

- `Ingredient`;
- `Dish`;
- `Event`.

### `menu_planning/calculations.py`

Содержит функции расчета количества порций и ингредиентов.

### `menu_planning/dishes.py`

Содержит функции для работы с коллекцией объектов `Dish`:

- поиск блюда;
- сортировка блюд;
- подсчет блюд по типу.

### `menu_planning/events.py`

Содержит функции для работы с коллекцией объектов `Event`:

- поиск события;
- добавление блюда в меню;
- удаление блюда из меню;
- проверка наличия блюда в меню.

### `menu_planning/storage.py`

Отвечает за загрузку и сохранение данных.

Выполняет преобразования:

- JSON -> объекты `Event`, `Dish`, `Ingredient`;
- объекты `Event`, `Dish`, `Ingredient` -> JSON.

### `menu_planning/utils.py`

Содержит вспомогательные функции:

- `input_int()` - безопасный ввод целого числа.

### `tests/`

Содержит автоматизированные тесты проекта.

Тесты проверяют:

- создание и работу объектов;
- методы классов;
- расчет ингредиентов;
- операции с меню события;
- преобразование JSON-данных в объекты.

## Требования

```bash
pip install -r requirements.txt
```

## Запуск приложения

Для запуска приложения выполнить:

```bash
python main.py
```

После запуска отображается главное меню:

```text
=== Система планирования праздничного меню ===
1. Показать события
2. Показать блюда
3. Найти блюдо по названию
4. Проверить блюдо в меню события
5. Добавить блюдо в меню события
6. Удалить блюдо из меню события
7. Показать меню события
8. Выход
```
